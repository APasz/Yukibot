These small archives contain owned test data, generated with RAR 6.24.
No RAR executable is included or required to generate fixtures during tests.

Each bundle contains `Wrapper/Mods/{First,Second}/ModInfo.xml` and
`Resources/asset.unity3d`. Metadata names match the folder names, with version
`1.0`; each asset contains `b"asset data" * 64`. `single-rar4.rar` contains only
First's files, with the wrapper removed.

The base command was `rar a -cfg- -r -ts- -mt1 -md1m ARCHIVE Wrapper`.
Variants use `-ma4`, `-ma5`, `-s`, `-ptest-password`, or `-hptest-password`.
`split.part1.rar` uses `-ma5 -m0 -v1k`; the later volumes are deliberately absent.
The symlink variant uses `-ma5 -ol` and a `First/link` pointing outside the
bundle. The hardlink variant uses `-ma5 -oh` and a `First/link` sharing the
metadata file's inode.
`unknown-size.rar` is the RAR5 bundle with the first file's unknown-size flag
set and its header checksum recalculated.

Compressed extraction checks require a full RAR backend, such as `unrar`.
Stored archives generated by `checks/rar_helpers.py` and rejection checks work
without one.
